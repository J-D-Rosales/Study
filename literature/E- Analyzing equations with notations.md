Let's say we have the next equation:
$$
2n^{2} +3n + 1 = 2n^{2} + \Theta(n) = \Theta(n^{2})
$$
We can analyze the equations as follows:
For the first equations we have that for some function $f(n) \in \Theta(n)$, there is some function $g(n) \in \Theta(n^{2})$ such that $2n^{2} + f(n) = g(n)$ for all n. The other side of the question will tell the same, but will less detail intervening two functions $g(n),h(n)$.
