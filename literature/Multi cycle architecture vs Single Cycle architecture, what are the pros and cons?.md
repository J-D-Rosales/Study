The weakness of the Single cycle architecture are, 
- It has two main memories
- Requires a clock signal to support the slowest instruction (lw)
- Use adders (which are expensive)
Therefore the Multi cycle architecture address these weaknesses by make on each cycle a process and handle all in one memory.
