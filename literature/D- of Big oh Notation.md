$$
O(g(n))= \{ f(n): \text{ there exists postive constants c and n0 such that } 0 \leq f(n) \leq cg(n) \text{ for all } n\geq n_{0}\}.
$$

<span style="color:yellow">Evidencia:</span>
We use Big-og to give us an upper bound on a function, to within a constant factor. For all values of n bigger than $n_{0}$ the value of $f(n)$ is on or below $cg(n)$.
Remember that $\Theta(g(n)) \subseteq O(g(n))$. Because $\Theta(g(n))$ is more restrictive and strong notation.
