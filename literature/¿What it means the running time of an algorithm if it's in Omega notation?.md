It means that the function $f(n)$ that is in $\Omega(g(n))$ the running time of the algorithm that for any given input $n$ it is at least cg(n) function. It could grow more, but at least the running time would be $cg(n)$.

However, we can't say that $\Omega(n^{2})$ is the running time for insertion sort, because it exist and input, let's say that is in $\Theta(n)$ time. However, we can say that $\Omega(n^{2})$ it's the worst case for insertion sort.
