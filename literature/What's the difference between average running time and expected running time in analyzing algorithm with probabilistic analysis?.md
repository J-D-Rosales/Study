<span style="color:yellow">IDEA:</span>
We refer to an **average running time** when the probability distribution is over the *inputs* of the algorithm, it means the input is random. 
We refer to an **expected running time**, when the algorithm itself make random choices. 


<span style="color:yellow">Evidencia:</span>
We can call the Hiring original problem as analyzing it's average running time. However if we modify the algorithm to let the boss make a random choice over the candidates, we would talk about expected running time.
