It's de idea of comparing functions. The types are: A function is:
1. **monotonically increasing**: if $m\leq n$ implies that $f(m)\leq f(n)$
2. **monotonically decreasing**: if $m\geq n$ implies that $f(m) \geq f(n)$
3. **strictly increasing**: if $m< n$ implies that $f(m) < f(n)$
4. **strictly decreasing**: if $m > n$ implies that $f(m) > f(n)$
