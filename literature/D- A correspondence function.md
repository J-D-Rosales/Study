It's called a function that can be maped one by one at his elements. In more formal way:
Assume that we have two sets A and B and a function f, from A to B. Say that f is **one-to-one** if it never maps two different  elements the same place ($f(a) \neq f(b)$) whenver $a \neq b$. Say that f is **onto** if it hits every element of B, that is for every $b \in B$ there is a $a \in A$ such that $f(a) =b$. Say the A and B are the same size if there is a one-to-one, onto function $f: A \to B$. A function that is both one to one and onto is called a **correspondence**. In a correspondence, every element of A maps a unique elment of B and each element of B has a unique element of A mapping to it. A correspondence is simply a way of pairing the elements of A with the elements of B.
