### La Solución "Sándwich" (Formal y Correcta)

Para probar esto, usamos el hecho fundamental de que el tiempo de ejecución real de _cualquier_ entrada ($T(n)$) siempre vive entre el mejor y el peor caso.

$$T_{best}(n) \le T(n) \le T_{worst}(n)$$

Aquí tienes la prueba paso a paso para corregir tu ejercicio:

#### Parte 1: Si $T(n) = \Theta(g(n))$ $\implies$ $O$ y $\Omega$ (Ida)

Si el tiempo de ejecución es $\Theta(g(n))$, significa que para cualquier entrada de tamaño $n$:

$$c_1 g(n) \le T(n) \le c_2 g(n)$$

- Como esto es cierto para todas las entradas, también es cierto para la peor entrada:
    
    $$T_{worst}(n) \le c_2 g(n) \implies T_{worst}(n) = O(g(n))$$
    
- Y es cierto para la mejor entrada:
    
    $$T_{best}(n) \ge c_1 g(n) \implies T_{best}(n) = \Omega(g(n))$$
    

#### Parte 2: Si $O$ y $\Omega$ $\implies$ $T(n) = \Theta(g(n))$ (Vuelta)

Esta es la parte que intentabas hacer en tu foto.

1. Sabemos que $T_{worst}(n) = O(g(n))$, por lo tanto existe $c_2$ tal que:
    
    $$T(n) \le T_{worst}(n) \le c_2 g(n)$$
    
    (El tiempo de cualquier algoritmo nunca supera su peor caso).
    
2. Sabemos que $T_{best}(n) = \Omega(g(n))$, por lo tanto existe $c_1$ tal que:
    
    $$c_1 g(n) \le T_{best}(n) \le T(n)$$
    
    (El tiempo de cualquier algoritmo nunca es más rápido que su mejor caso).
    
3. El Sándwich: Unimos (1) y (2):
    
    $$c_1 g(n) \le T(n) \le c_2 g(n)$$
    
1. **Conclusión:** Por definición, esto significa que $T(n) = \Theta(g(n))$.

### La Solución Formal (Paso a Paso)

Para arreglar tu prueba, solo necesitamos elegir una constante específica para generar el conflicto.

**Prueba por Contradicción:**

1. Supongamos que existe una función $f(n)$ que pertenece a ambos conjuntos: $o(g(n)) \cap \omega(g(n))$.
    
2. Como $f(n) \in o(g(n))$, la definición vale para **cualquier** constante. Elijamos **$c = 1$**.
    
    - Existe $n_1$ tal que $f(n) < 1 \cdot g(n)$.
        
3. Como $f(n) \in \omega(g(n))$, la definición vale para **cualquier** constante. Elijamos **$c = 1$**.
    
    - Existe $n_2$ tal que $1 \cdot g(n) < f(n)$.
        
4. Sea $n_0 = \max(n_1, n_2)$. Para todo $n \ge n_0$, ambas cosas deben ser ciertas:
    
    $$g(n) < f(n) < g(n)$$
    
5. **Contradicción:** $g(n)$ no puede ser estrictamente menor que sí mismo.
    
6. $\therefore$ La intersección es vacía ($\emptyset$).
