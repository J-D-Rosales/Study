>Language A is Polynomial time mapping reducible to language V if a polynomial reducible time computable function $f: f \Sigma^{*} \to \Sigma^{*}$ exists for every $w$.
>$$
>w \in A  \leftrightarrow  f(w) \in B
>$$
>The function f is called polynomial time reduction to A and B.
