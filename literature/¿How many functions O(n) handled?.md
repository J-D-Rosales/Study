<span style="color:yellow">IDEA:</span>
Different from our normal thinking, we should now that every function below $O(g(n))$ is also in $O(g(n))$.  

<span style="color:yellow">Evidencia:</span>
We could say for example that any lineal function is also in $O(n^{2})$. Because it's an upper bound, there is not a lower bound that exists.
