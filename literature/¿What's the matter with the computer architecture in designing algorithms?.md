When we design algorithms, if we don't have care in the specification of the RAM, instructions, memory size, etc. The performance of such algorithms will vary and others with high input would require some amount of bits. 


<span style="color:yellow">Evidencia:</span>
Some computers can do operations in constant time, for example the shifting right can have an impact in power $2^{k}$, where every shifting is multiply by 2. 
Also it's important to restrict the amount of data, because if not we can store arrays and sum them in constant time, and other operation, that's why for $n$ input, the word size should be $c\log n$, and c is constant for the input to don't grow arbitrarily.
