<span style="color:yellow">IDEA:</span>
It is a simplification of the running time of an algorithm, the simplification it's so abstract that it just takes the greater term of n, the greater growth. We use the $\Theta$ notation to assert the worst case.


<span style="color:yellow">Evidencia:</span>
We say that an algorithm it's more efficient than other if the worst case running time has a lower order of growth. A $\Theta(n^{2})$ will with larger n inputs run faster than $\Theta (n^{3})$ running time.
