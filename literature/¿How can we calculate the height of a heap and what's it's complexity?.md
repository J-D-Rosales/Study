<span style="color:yellow">IDEA:</span>
To calculate the height of a heap we need to view it as a tree. Let's see the rules:
- The height of any node is the number of edges of the simplest path from the node to a leaf.
- The height of a heap is the height of the root
Since, the heap is view as a tree, we know that calculate his height will take $\Theta(lg(n))$ where $n$ is the number of nodes. And the basic operations for the heap will take $O(lg(n))$ time.
