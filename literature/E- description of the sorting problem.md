The idea is to sort certain elements in an array, we can abstract the problem as follows:
<span style="color:	#87CEEB">Input</span> : Sequence of numbers n, $\langle a_{1},a_{2},a_{3},\dots,a_{N} \rangle$ 
**output**: Permutation (reorderig) $\langle a_{1}',a_{2}',a_{3}',\dots,a_{n'}\rangle$ of the input sequence such that $a_{1}' \leq a_{2}' \leq \dots\leq a_{n}'$

>[!tip] Keys
>The numbers of we want to wish is also called keys.
