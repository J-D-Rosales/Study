<span style="color:yellow">IDEA:</span>
Really there is no type, but classification.
When the function is $f(n) = \Theta (g(n))$ it means it is tight between some other two functions, so we say it is **asymptotically thigh bound**. That is $f(n)$ is equal to g(n) but differing in a constant.
Now, the definition requieres that every $f(n) \in  \Theta(g(n))$ must be greater than 0, meaning it is **asymptotically nonnegative**. So, $g(n)$ needs to be nonnegative also, that's for sufficient large number of n. Otherwise, the set $\Theta(g(n))$ is empty.
