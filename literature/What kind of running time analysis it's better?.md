<span style="color:yellow">IDEA:</span>
Depends on the specific application you are doing. However, we could state that, the  common way to make the analysis is by stating the worst case possible running time. 

<span style="color:yellow">Evidencia:</span>
Reasons:
- The worst case running time will give you a good upper bound, in which nothing will pass over that bound. 
- Some algorithms will take the worst case often, when checking null elements for example.
- The average case is often roughly as bad as the worst case, an example is insertion sort, in which will still be quadratic.
