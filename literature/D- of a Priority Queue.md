<span style="color:yellow">IDEA:</span>
A priority Queue is an Data structure, or better saying a set of elements $S$, where each element has it's associated value called  **key**. 

<span style="color:yellow">Evidencia:</span>
It's like a regular Queue, but instead of FIFO, it is done by it's order of priority. No matter the insertions or the eliminations.
