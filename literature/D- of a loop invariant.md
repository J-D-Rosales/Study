It is an invariant or properties stated that does not going to change during the algorithm or the for loop. This is key to understand why an algorithm works. However, we need to show three things about a loop invariant. 

**Initialization:** It is true in the first iteration of the loop
**Maintenance** : Stays as true after the first iteration of the loop and after that next iteration
**Termination**: When finished the property that loop invariant gives us is helpful to show that the algorithm is correct.
