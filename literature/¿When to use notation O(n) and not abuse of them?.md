<span style="color:yellow">IDEA:</span>
We should use $O(n)$ notation, when we want to write an upper bound. When, we use an algorithm we can use $O(f(n))$ to describe the worst case running. However, the time it takes or the bounds can vary, that's why we should careful use notation, the running time of the algorithm it's depending on it's input.


<span style="color:yellow">Evidencia:</span>
For example, in insertion sort the Worst case is $\Theta(n^{2})$, but if the input is already sorted the running time is $\Theta(n)$, therefore saying that the running time of insertion sort is $O(n^{2})$ it is an abuse. Since, it can vary depending on the input.
