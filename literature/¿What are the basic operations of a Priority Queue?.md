You could add a lot more, but the indispensable ones are:
**Insert(S,x,k):** Inserts the element $x$ with the key $k$ into the set $S$. $S = S\cup \{ x \}$. 
**Maximum(S)**: Returns the element with the largest key.
**Extract(S)**: Remove and returns the element with the largest key. 
**Increase-Key**: Increments the value of an element $x's$ key to a new value k, assuming that the new value $k$ is greater than the old key.
