Now, we are gonna manage the way we describe the algorithms as follows:
$O_{1},O_{2},O_{3}\dots,O_{k}$. -> Objects inputs, representing numbers, etc
$\langle O_{1},O_{2},O_{3}\dots,O_{k}\rangle$ -> Object inputs converted to strings
We assume the machine will convert that into the specific input we need. 
The first line of the algorithm it's his input. Now, when an input of an object is $\langle A \rangle$ we assume the machine will check if that input is correct (in a way to deconstruct to a string).
