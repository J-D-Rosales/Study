The language $B = \{ w\# w ~| ~ w \in \{ 0,1 \}^{*} \}$
The strategy is doing with zig zad method. the algorithm is as follows
1. We read the first symbol and marked that, then go to the symbol not marked after the # symbol.
2. Make a zig zag, if a symbol is not equal reject, or the symbol # is not found reject. 
3. After read all the symbols from the left part, check if there is a remaining symbol on the right part, if it is, reject , otherwise accept.
