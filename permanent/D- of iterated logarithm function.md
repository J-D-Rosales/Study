The logarithm $f^{(i-1)}(n) > 0$, in order to be defined then, we defined the iterated logarithm function :
$$
lg^{*} n = min \{ i \geq 0: \log ^{(i)} n \leq 1 \}
$$


<span style="color:yellow">Evidencia:</span>
This means, we are going to apply the logarithm for i times, looping i, until we find the smallest integer such that the i-est we have apply the logarithm it's 1 or less.
This functions growths really slow
$lg^{*}2 = 1$
$$
\begin{align}
\log^{*} 4 = 2 \\
\log ^{*} 16 = 3 \\
\log ^{*} 65536 = 4 \\
\log ^{*} (2^{65536}) = 5
\end{align}
$$
Remember that the function in order to get 5, needs a number that it's more than the atoms in the universe, therefore, we take it this function as a constant.
