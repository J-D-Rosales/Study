<span style="color:yellow">IDEA:</span>
A configuration is a set of three items
- the current head location
- The current tape contents 
- Current states
Then, we can have different configurations, usually is written as follows
$uqv$, where $uv$ are for the content of the tape, q the current state, and the first symbol of $v$ is the head. 

<span style="color:yellow">Evidencia:</span>
An example is $1001q_{7}110$ where is a configuratin where the state is $q_{7}$, the tape is $1001110$ and the head is the third 1.
