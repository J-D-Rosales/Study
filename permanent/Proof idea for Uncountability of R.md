Let's say we have R that is countable (the proof it's gonna be by contradiction). Suppose it exist a Correspondence function between R and N as de definition for countability assures [[D- countability and uncontability for sets]]. Therefore, we'll construct The function and show this is imposible.
Let's put the numbers in the table

| n   | f(n)        |
| --- | ----------- |
| 1   | 1.2323..    |
| 2   | 55.555...   |
| 3   | 0.5.....    |
| 4   | 0.12345.... |
As you can see maybe we can count them. HOwever, imagine we want to create a new number let's called x. Be careful, because or numbers such that 0 or 9, $1.999\dots = 1$. SO we choose just numbers between 1 and 8. So for the example our new number would be:
2 (differs form the first number)
2.3
2.34
2.345...
But wait that number  is not in f(n) but it is sure in real numbers. Therefore R is uncountable.
