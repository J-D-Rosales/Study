>[!note] Definition
>**Pumping Lemma for context free languages** . If A is a context free language, the there is a number $p$ (pumping length) where, if $s$ is a string in A of length of at least p, the $s$ can be divided into five pieces $s = uvxyz$ satisfying the conditions
>1. for each $i\geq 0$,  $uv^{i}xy^{i}z \in A$,
>2. $|vy| > 0$
>3. $|vxy| \leq p$
