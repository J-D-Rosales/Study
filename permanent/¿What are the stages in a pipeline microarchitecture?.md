The stages are similar to the lw instructions:
- Fetch: Read instructions from memory
- Decode : Processor reads the source operands to produce the signals 
- Execute: Perform a computation with the ALU
- Memory: Write or read depending on the instruction 
- Writeback: Write to the register file the data is needed
