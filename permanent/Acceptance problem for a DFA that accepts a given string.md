<span style="color:yellow">IDEA:</span>
It test whether a DFA accepts a given string, $A_{DFA}$.  It can be expressed:
$$
A_{DFA} : \{ \langle B, w \rangle | B\text{ is a DFA that accepts input string w} \}
$$
The problem is the same as says $\langle B, w \rangle$ is a part of the language. 
Showing that the language is decidable is the same as showing that the computational problem is decidable.
