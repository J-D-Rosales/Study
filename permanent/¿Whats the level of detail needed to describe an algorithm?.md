We could have three leves:
*Formal description*: It is when you show all the machine of the turing machine, show states, rejects, transitions, etc. It is the most accurate way to describe an algorithm
*Implementation description*: It is when you describe the behave of the turing machine, such things like, where the head would be, how it would behave, etc. 
*HIgh level description*: Here, we do not focus on describe a turing, rather we give the information needed to describe how the algorithm works, ans in essence know how to implement if you are good with Turing machines.
