<span style="color:yellow">IDEA:</span>
Having a problem A that has a time complexity and it is reducible to B, then we can use B to solve A. However, since it's time complexity we state that *A is efficiently reducible to problem B, a efficient solution to B can be used to solve A efficiently*.


<span style="color:yellow">Evidencia:</span>
Just imagine, having the B problem we make a conversion to A, with $\tau$ cost that is less than the original cost of solving the problem B, and therefore, we can say that A has time complexity of $O(B) +\tau$, being O(B) the time it takes to solve problem B-
