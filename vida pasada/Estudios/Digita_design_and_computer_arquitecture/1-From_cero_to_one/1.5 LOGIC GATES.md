>[!note] Logic gates
>Are simple digital circuits that take one or more binary inputs and produce a binary output.

Logic gates are drawn with a symbol showing the inputs and the output. Inputs are usually drawn on the left (or top) and outputs on the right (or bottom).
*Insight*: The relationship between the inputs and the output can be described with a truth table or a Boolean equation.
A boolean equation is a mathematical expression using binary variables.

# 1.5.1 NOT Gate
It has one input, A, and one output, Y. 
The output is the inverse of its input.
In the figure there is the truth table and the boolean equation.
$Y = \bar{A}$ is read "$Y$ equals NOT A". 
The NOT gate is also called an *inverter*.
>[!warning] Other notations
>Exists other notations of NOT (~,!,A') etc

# 1.5.2 Buffer
This simply copies the input into the output.
Logically this is useless. However, from the analog point, the buffer could deliver large amounts of current to a motor, or deliver data quickly. 
That's why we need abstraction to fully understand the system.
The triangle symbol indicates a buffer.
A circle on the output is called a bubble and indicates inversion. (in the NOT gate).
# 1.5.3 AND Gate
This is true only if the two of the inputs are true.  The inputs are listed int he order as if you were counting in binary.
There are others ways of write this: $Y = A \cdot B$,$Y=AB$,$Y = A \cap B$.
We prefer $Y = AB$, read "Y equals A and B".
# 1.5.4 OR Gate
Produces true if either A or B (or both) are TRUE. 
The equation is written $Y = A + B$ or $Y = A \cup B$. This is read "$Y \text{ equals } A \text{ or } B$"
Image on the book [[Digital Design & Computer Architecture RISC-V Edition.pdf]] p.19
# 1.5.5 Other Two-Input Gates
**XOR**($\oplus$) "exclusive or": is TRUE if A or B, bot not both are TRUE.
Any gate can be followed by a bubble to invert its operation. The NAND gate performs NOT AND. The NOR gate performs NOT OR. An N-Input XOR gate is sometimes called a parity gate and produces TRUE output if an odd number of inputs are TRUE.
