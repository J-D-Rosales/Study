boolean algebra is based on a set of axioms that we assume are correct. Axioms are unprovable in the sense that a definition cannot be proved. From the axioms we prove the theorems carried by them.

Axioms and theorems of Boolean algebra obey the principle of fuality. If symbols 0 and 1 and the operators $\cdot$(AND) and $+$ (OR) are interchanged, the statement will still be correct. We use (´) to denote the *dual* of a statement.

# 2.3.4 The truth behind it all
The way to prove a theorem that has finite variables is easy, just show that the theorem holds for every value of these variables, this is called *perfect induction*.
# 2.3.5 Simplifying equations
The theorems of Boolean algebra help us simplify Boolean equations. Considering the SOP $Y = \bar{A} B + AB$. By combining theorem the equation simplifies to $Y = B$.
We define an equation in sum-of-products form to be *minmized* if it uses the fewest possible implicants. If there are several equations with the same number of implicants, the minimal one is the one with the fewest literals.
>[!note] Prime implicant
>An implicant that cannot be combined with any other implicant in the equation to form a new implicant with fewer literals.

Sometimes, as example in the book shows, it is better expand an implicant to make the minimization of an equiation.
