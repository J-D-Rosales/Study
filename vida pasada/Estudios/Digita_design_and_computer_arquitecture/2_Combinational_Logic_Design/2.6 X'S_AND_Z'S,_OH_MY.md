# 2.6.1 Illegal Value X
Indicates that the circuit node has an *unknown or illegal* value. Commonly happens when is trying to drive bot 0 and 1 values, this is called *contention*.
![[Screenshot from 2025-09-07 16-30-43.png]]
Contention also can cause large amounts of power to flow between the fighting gates, resulting in the circuit getting how and possibly damaged.
Also, represents and uninitialized value, to warn you.
# 2.6.2 Floating Value: Z
Indicates that a node is being driven neither HIGH not LOW.
It is not always 0, might be 1, might be some value in between, depending on the history of the system. 
This is not an error, as long as some other circuit element does drive the node to a valid state. 
One way to produce this state is to forget to connect a voltage to a circuit input.
>[!note] Tristate buffer
>Has three possible output, HIGH, LOW, and floating (Z).

It has input A, output Y and enable E. When E is TRUE the tristate buffer acts as a simple buffer, but in other case, it permits the floating value Z.
The tristate buffer has an active high enable. That is, when the enable is HIGH (1), the buffer is enabled. active low enable is with LOW (0).
