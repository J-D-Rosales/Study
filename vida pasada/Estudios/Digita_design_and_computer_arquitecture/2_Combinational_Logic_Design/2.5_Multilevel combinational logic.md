Logic in sum-of-products for is called *two-level logic* because it consists of literals connected to a level of AND gates connected to a level of OR gates. Most of the time, the levels of logic are greater, but reduce the use of hardware, so is in fact a win to win.
# Hardware Reduction
When you use just two level logic implementation, you certainly will have problems with $N-$inputs. For example a three input XOR, in equation will be:
$$
Y = \bar{A} \bar{B} C + \bar{A} B \bar{C} + A \bar{B} \bar{C} + A B C
$$
 Just imagine implementing this with or's and and's.
 In order to improve this, we can build the tree input XOR with two input XOR's.

# 2.5.2 Bubble Pushing
CMOS circuits prefer NAND's and NOR's over AND's and OR's
We do bubble pushing because it is difficult to read multilevel circuits just by inspection. But, with a bubble pushing it is easier to do that, just follow the rules.
- Begin at the output of the circuit and work toward the inputs
- Push any bubbles on the final output back toward the inputs so that you can read an equation in terms of the output (for example Y) instead of the complement of the output ($\bar{Y}$).
- Working backward, draw each gate in a form so that bubbles cancel. If the current gate has an input bubble, draw the preceding gate with an output bubble. If the current gate does not have an input bubble, draw the preceding gate without an output bubble.
