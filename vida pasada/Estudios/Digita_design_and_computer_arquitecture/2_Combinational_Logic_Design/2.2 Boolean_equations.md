Boolean equations deal with variables that are either TRUE or FALSE.
# 2.2.1Terminology
The complement of a variable $A$ is its inverse $\bar{A}$. 
The variable or its complement is called a *literal*. (e.g $A,\bar{A},B$ ans $\bar{B}$ are literals). We call $A$ the true form of the variable and $\bar{A}$ the complementary form.
___
The AND of one or more literals is called a *product* or an *implicant*. (e.g: $\bar{A}B,A \bar{B} \bar{C}$ and B are implicants) for a function of three variables.
___
A minterm is a product involving all of the inputs to the function. ($A \bar{B} \bar{C}$) is a minterm for a function of the three variables, but $\bar{A}B$ is not.
___
Similarly the OR of one or more literals is called a *sum*. A *maxterm* is s sum involving all of the inputs to the function. $A+ \bar{B} + C$ is a maxterm.
The *order of operations* is important when interpreting boolean equation.
In the ranking first is NOT, then AND, OR. 
# 2.2.2 Sum-of-Products Form
A truth table of $N$ inputs contains $2^{N}$ rows. Each row in a truth table is associated with a minterm that is TRUE for that row.
![[truth_table_sum_products.png]]
The first minterm for the first row is $\bar{A} \bar{B}$ because is TRUE when $A = 0, B = 0$.
We can write a boolean equation for any truth table by summing each of the minterms for which the output, $Y$, is TRUE. In the image, you see there is only one $\bar{A}B$. Thus, $Y = \bar{A}B$.
This is called SOP the canonical form of a function.
The sum-of-products canonical form can also be written in *sigma notation* using the summation symbol, $\sum$. With this notation the function would be written
$F(A,B) = \sum(m_{1})$ or $F(A,B) = \sum(1)$
If there is more minterms, just add a comma and put it through.
# 2.2.3 Product-of-Sums Form (pos)
Each row of a truth table corresponds to a maxterm that is FALSE for that row. The POS can also be written using the product symbol, $\Pi$.
Is like the inversa of SOP. Here you search for the false output and put the maxterm there. For example: $Y = (A+B)(\bar{A} +B)$.
