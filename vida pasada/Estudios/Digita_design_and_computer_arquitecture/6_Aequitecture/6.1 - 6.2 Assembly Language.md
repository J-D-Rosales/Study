Now we'll jump up to define the architecture of a computer. It is defined by the instruction set (language and operand locations).
<span style="color:yellow">Example</span> : ARM, x86, MIPS, SPARC, and Power PC.
- The words in a computer's language are called *instructions*. 
- The computer's vocabulary is called the *instruction set*
The operands may come from memory, from registers, or from the instruction itself.
Instructions are encoded as binary numbers (machine langauge). The ARM architecture represents each instruction as 32-bit word. Microprocessors are digital systems that read and execute machine language instructions.
Instructions sets are similar, but different in small things (michroarquitecture commonly).
An example of this is AMD and Intel with the same x86 architecture.
We'll follow four principles articulated by David Patterson and John.
1. Regularity Supports simplicity
2. Make the common case fast
3. Smaller is faster
4. Good design demands good compromises

## 6.2.2 Operands: Registers, Memory, and Constants
**An instruction operates on *operands*** 
the variables a,b,c in the examples are all operands. However, computers just operates with 0's and 1's. Then, it needs a physical location from which to retrieve the binary data. 
Operands can be stored in registers or memory, or they may be constants stored in the instruction itself.
-> Operands stored as constants or in registers are accessed quickly, but they hold only a small amount of data.
>[!tip] ARM 32-bit architecture
>It is called 32-bit architecture because it operates on 32-bit data.

### Registers
Most architectures specify a small number of registers that hold commonly used operands. The ARM architecture uses 16 registers (*register set*). These registers are used by instructions to hold data temporarily while the CPU works on them. When an instruction needs to perform an operation (like addition or comparison), the operands will be in these registers, allowing the CPU to work quickly.
>[!tip] Design principle 3: Smaller is faster
>Fewer the registers, the faster they can be accessed. So, reading data from a small register file is faster than reading it from a large memory. 

<span style="color:green">Curiosity</span>: A register file is typically built from a small SRAM array.
ARM register names are preceded by the letter 'R'.
Variables a,b, and c, are arbitrarily placed in R0,R1, and R2.
*The instruction adds the 32-bit vaues contained in R1(b) and R2(c) and writes the 32-bit result to R0 (a)*.
![[Screenshot from 2025-09-25 11-34-36.png]]
<span style="color:	#87CEEB">Example 6.1</span> Translate the following code into ARM assembly language. a-c are held in registers R0-R2 and f-j are in R3-R7.
```cpp
a = b-c
f = (g + h) - (i + j);
```

```assembly
; ARM assembly code
; R0 = a, R1 = b, R2 = c, R3 = f, R4 = g, R5 = h, R6 = i, R7 = j
SUB R0, R1, R2 ;a=b−c
ADD R8, R4, R5 ; R8 = g + h
ADD R9, R6, R7 ; R9 = i + j
SUB R3, R8, R9 ; f = (g + h) − (i + j)
```
We don't need to assign the R's, Assembly assign a memory address for that.

### Constants / Immediates.
- A **constant** or **immediate** is a **value** that is directly embedded in the instruction itself, rather than being stored in memory or in a register.
- This means that the value is **immediately available** when the instruction is executed and does not need to be fetched from a register or memory.
The immediate is preceded by the # symbol and can be written in decimal or hexadecimal. Immediates are unsigned 8- to 12-bit numbers.
![[Screenshot from 2025-09-25 11-47-58.png]]

The move instruction (MOV) is a useful way to initialize register values. MOV can also take a register source operand. For example, MOV R1,R7 copies the contents of register R7 into R1.
### Memory.
It's bigger, but slow, but continues being bigger.
In the ARM architecture, instructions operate exclusively on register, the data stored in memory must be moved to a register before it can be processed.
Remember that memories are organized as an array of data words. ARM architecture uses 32-bit memory addresses and 32-bit data words.
