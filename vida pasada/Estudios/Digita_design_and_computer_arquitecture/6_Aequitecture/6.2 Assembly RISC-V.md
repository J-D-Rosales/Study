## Operands: Registers, Memory, and constants.
**An instruction operates on operands**. Operands like a or b or c. However, we need a physical location to retireve the binary data. Operands can be stored in registers or memory, or may be constants stored in the instruction itself.
Operands stored as constants or in registers are accessed quickly, but no a lot of data.  Additional data must be accessed from memory, which have large quantity but is slow. 
RISC-V is called a 32 bit architecture -> operates in 32-bit-data.
### Registers.
Most architectures have a small quantity of registers, to hold common operands. RISC-V architecture has 32 registers (register set). This is stored in a small multiported memory called a *register file*.

### Constants/ Immediates
Instructions can use constant or immediate operands. Their values are immediately available form the instruction and do not require a register or memory access.
The add immediate instruction, addi, that adds an immediate to a register. IN assembly the immediate can be written in decimal, hexadecimal, or binary.

![[Screenshot from 2025-10-01 11-39-11.png]]
Hexadecimal constants starts with 0x and binary constants start with 0b.
addi, is useful also to initialize variables i,x and y to constants. 
To create larger constants, use a *load upper inmmediate* instruction (lui) followed by an add immediate instruction (addi). The lui instruction loads a 20-bit immediate into the most significant 20 bits of the instruction and places zeros in the least significant bits. 
Remember that register can store 32 bit numbers.
When creating large immediates, if the 12-bit immediate in addi is negative, the **upper immediate** in the lui must be incremented by one. Remember that addi sign-extends the 12-bit immediate, so a negative immediate will have all 1's in its upper 20 bits. Because all 1's is -1 in two's complement, adding all 1's to the upper immediate results in subtracting 1 from the upper immediate. AN example is the next, where the desired 20-bit upper immediate, 0xFEEDA, is incremented by 1.

### Memory
Data can also be stored in memory. Memory is larger and slowe.
In the RISC-V architecture, instructions operate exclusively on registers, so data stored in memory must be mobed to a register before it can be processed. 
>[!danger] RISCV
>RISC-B USES A BYTEADDRESSABLE MEMORY.

It is that each byte in memory has a unique address..
Each word address is a multiple of 4. 
![[Screenshot from 2025-10-01 12-06-26.png]]
The most significant byte (MSB) is on the left and the least significant byte (LSB) is on the right.
The *load word* instruction, lw, reads a data word from memory into a register. ![[Screenshot from 2025-10-01 12-09-43.png]]
IN the xample, it loads memory word 2, located at address 8, into a(s7). 
TH elw instruciton specifies the memory address using an offset added to a *base register*. Recall that each data word is 4 bytes, so the word address is four rimes the word number.Word number 0 is at address 0, word 1 is ar address 4, word 2 ar address 8, and so on. 
In this example, the base register, zero, is added to the offset, 8, to get address 8, or word 2.  s7 then holds the value 0x01EE2842, which is the data value stored at memory address 8.
The store word instruction, *sw*, writes a data word from a register into memory.
