# Formal definition of a nondeterministic finite automaton
They differ just on type of transition function.  In a DFA, the transition function takes a state and an input symbol and produces the next state. In NFA it produces the set of possible next states. But first:
For any set $Q$ we write $\mathcal{P}(Q)$ to be the collection of all subsets of $Q$. Here $\mathcal{P}(Q)$ is called the **power set** of $Q$. For any alphabet $\sum$ we write $\sum_{ \epsilon}$ to be $\sum \cup \{ \epsilon \}$. 
>[!note] Definition 1.37
>A **nondeterministic finite automaton** is a 5-tuple $\left( Q,\sum,\delta, q_{0},F \right)$, where
>1. $Q$ is a finite set of states,
>2. $\sum$ is a finite alphabet
>3. $\delta : Q \times \sum_{\epsilon}\to \mathcal{P}(Q)$ is the transition function,
>4. $q_{0} \in Q$ is the start state, and
>5. $F \subseteq Q$ is the set of accept states.

Now, the definition of computation for an NFA.
Let $N = \left( Q,\sum,\delta,q_{0},F \right)$ be an NFA and $w$ a string over the alphabet $\sum$. Then we say that $N$ **accepts** $w$ if we can write $w$ as $w = y_{1}y_{2}\dots y_{m}$, where each $y_{i}$ is a member of $\sum_{\epsilon}$ and a sequence of states $r_{0},r_{1},\dots,r_{m}$ in $Q$ with three conditions:
1. $r_{0} = q_{0}$
2. $r_{i+1} \in \delta(r_{i},y_{i+1})$, for $i= 0,\dots,m-1$ and
3. $r_{m} \in F$
Condition 2 says that state $r_{i+1}$ is one of the allowable next states when $N$ is in state $r_{i}$ and reading $y_{i+1}$. Observe that $\delta(r_{i},y_{i+1})$ is the set of allowable next states and so we say that $r_{i+1}$ is a member of that set.

# Closure under the regular operations
Our aim is to prove that the union, concatenation, and star of regular languages are still regular.
We want to prove the next theorem:
>[!tip] theorem 1.45
>The class of regular languages is closed under the union operation

Because I want to show the proof, I'll show it.
<span style="color:	#87CEEB">Proof idea</span>:
WE have regular languages $A_{1}$ and $A_{2}$ and want to prove that $A_{1} \cup A_{2}$ is regular. The idea is to take two NFAs, $N_{1}$ and $N_{2}$ for $A_{1}$ and $A_{2}$, and combine them into one new NFA, N.
Machine $N$ must accept its input if either $N_{1}$ or $N_{2}$ accepts this input. The new machine has a new start state that branches to the start states of the old machines with $\epsilon$ arrows. 
SO, the new machine nondeterministically guesses which of the two machines accepts the input. If one of them accepts the input $N$ will accept it, too. 
![[Screenshot from 2025-09-09 10-28-22.png]]
Let's prove it.
<span style="color:red">Proof:</span>
Let $N_{1} = (Q_{1},\sum, \delta, q_{1}, F_{1})$ recognize $A_{1}$, and  $N_{2} = (Q_{2},\sum, \delta, q_{2}, F_{2})$  recognizes $A_{2}$.
Now we construct $N = (Q,\sum,\delta,q_{0},F)$ to recognize $A_{1} \cup A_{2}$.
1.- $Q = \{ q_{0} \} \cup Q_{1} \cup Q_{2}$. The states of N are all the states of $N_{1}$ and $N_{2}$, with the addition of a new start state $q_{0}$.
2.- The state $q_{0}$ is the start state of $N$.
3.- The set of accept states $F = F_{1} \cup F_{2}$. The accept state of $N$ are all the accept states of $N_{1}$ and $N_{2}$. That way, N accepts if either $N_{1}$ accepts or $N_{2}$ accepts.
4.- Define $\delta$ so that for any $q \in Q$ and any $a \in \sum_{\epsilon}$,

$$
\begin{align}
\delta(q,a) = \begin{cases}
\delta_{1}(q,a)  & q \in Q_{1} \\
\delta_{2}(q,a)  & q \in Q_{2} \\
\{ q_{1},q_{2} \} & q = q_{0} \text{ and } a = \epsilon  \\
\emptyset & q = q_{0} \text{ and } a \not= \epsilon
\end{cases}
\end{align}
$$
With NFA this prove is relatively easy.
