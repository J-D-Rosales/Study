# The pumping Lemma for regular languages.
This theorem states that all regular languages have a special property. If we can show that a language does not have this property, we are guaranteed that it is not regular. 
The state is: *All strings in the language can be "pumped" if they are at least as long as a certain special value called the **pumping length***. THat means each such string contains a section that can be repeated any number of times with the resulting string remaining in the language.
>[!tip] Theorem 1.70 Pumping Lemma
>If A is a regular language, the there is a number $p$ (the pumping length) where if $s$ is any string in $A$ of length at least $p$, then $s$ may be divided into three pieces, $s = xyz$, satisfying the following conditions:
>1. for each $i\geq 0,xy^{i}z \in A$
>2. $|y| > 0$, and
>3. $|xy| \leq p$

When $s$ is divided into $xyz$, either $x$ or $z$ may be $\epsilon$, but condition 2 says that $y \not= \epsilon$.
Condition 3 states that the pieces $x$ and $y$ together have length at most $p$. It is an extra, but it will be useful.
The proof of the pumping lemma is in the book.
How you should approach a problem to prove a langauge B is not regular.
>[!example] Steps to prove a language is not regular
>1. Assume that B is regular in order to obtain a contradiction.
>2. Then use the pumping lemma to guarantee the existence of a pumping length  $p$ such that all strings of lenght $p$ or greater in $B$ can be pumped. 
>3. Find a string s in $B$ that has length $p$ or greater but that cannot be pumped. 
>4. Finally, demonstrate that $s$ cannot be pumped by considering all ways of dividing $s$ into $x,y$ and $z$. And, for each such division finding a value $i$ where $xy^{i}z \not\in B$. 

The existence of that $s$ contradicts the pumping lemma if B were regular, therefore it is not. 
I'll let an example on how to do it. But just one, to make you remember. The rest are in the book.
<span style="color:	#87CEEB">Example 1</span>:
Let $B$ be the language $\{ 0^{n}1^{n} | n \geq 0 \}$. We use the pumping lemma to prove that $B$ is not regular. 
1. We assume that B is regular.
2. Let $p$ be the pumping length given by the pumping lemma.
3. Choose $s$ to be the string $0^{p}1^{p}$, because $s$ is a member of $B$ and $s$ has length more than $p$, the pumping lemma guarantees that $s$ can be split into three pieces, $s = xyz$, where for any $i\geq 0$ the string $xy^{i}z \in B$. Let's consider the cases:
First: The string $y$ consists only of 0s. In this case, the string xyy< has more 0s than 1s, and so is not a member of B.
Second: The string Y consists only of 1s. Which is clearly a contradiction
Third: The string $y$ consists of both 0s and 1s. In this case the string $xyyz$ may have the same number of 0s and 1s, but they will be out of order with some 1s before 0s . Hence is not a member of $B$ which is a contradiction. 
Thus, a contradiction is unavoidable if we make the assumption that $B$ is regular, so B is not regular. Note that we can simplify this argument by applying
condition 3 of the pumping lemma to eliminate cases 2 and 3.
