Para conocer al cliente lo podemos hacer de distintas maneras, de manera grupal un focus group, entrevistas, etc. Esto es importante para conocer el perfil del cliente. Saber cómo hacerlo.
___
Después de un tiempo el cliente cambia. No podemos estar seguros del cliente, va y vuelve. 
Se debe hacer un descubrimiento de clientes con diferentes herramientas. Empezar con una lista pequeña de personas, contactar en pocas palabras. 
Debemos tener un guión listo. No hacerlo como llamada telefónica. 
___
