Existen tipos de data.
La data estructurada son las que están como en csv, o en json, que tienen un orden una estructura,etc.
La data no estructurada es una data que es dificil de procesar para reestructuraarle, etc. Por ejemplo, las imágenes.
Data semiestructrada son como el Json o el parquet.
Lugares donde puedo almacenar la data son:
- Data warehouse: Almacenar data estructurada
- Data lake: Almacenar data no estructurada. (spark para procesar)
