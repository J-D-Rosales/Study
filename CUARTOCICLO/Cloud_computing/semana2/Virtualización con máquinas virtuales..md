Objetivos: Entender las máquinas virtuales.
**Conceptos:**
Virtualización: Existen dos formas
- El software de hipervisor se instala directamente sobre el hardware
- El software del hipervisor se ejecuta en un sistema operativo host.
El hipervisor es un sistema operativo que se encarga solo de administrar el hardware. 
En cada máquina virtual le colocas un sistema operativo. 
___
Respecto al costo, determinaron:
- Compute
- Storage
- Data out
La forma más usual es bajo demanda.
