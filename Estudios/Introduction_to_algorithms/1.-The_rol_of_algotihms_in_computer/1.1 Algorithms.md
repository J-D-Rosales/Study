>[!note] algorithm
>Is informally defined as a sequence of computacional steps that transforms the **input** into an **output**

Normally the algorithm solve some computational problems. 

>[!note] Instance
>An instance of a problem consists of the input (satisfying the constraints) needed to computa a solution to the problem.

An algorithm is said to be **correct** if, for every input instance, it halts with the correct output.
A correct algorithm **solves** the given computational problem.
There are a lot of applications. Also, the seek is to find the best algorithm that fits every problem, but such algorithms are not easy to find.
>[!note] Data structures
>A **data structure** is way to store and organize data in order to facilitate access and modifications.

There are some problems that are NP-completes, or some problems that does not have efficient algorithms.
>[!note] Parallelism
>Make many operations by the cores of the computer making a parallel computer.
